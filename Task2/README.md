### База знаний

База знаний сформировна на основе Вики о вселенной Дозоров по произведениям Сергея Лукьяненко: [dozory.fandom.com](https://dozory.fandom.com/).

Термины заменены на похожие, но вымышленные, например Ночной - Чёрный, Дозор - Патруль, Медведь - Мышь и т.п.

Формировалась в несколько этапов:

1\. Скачан, распакован и преобразован архив Вики с [archive.org](https://archive.org).

Эта логика живёт в скрипте ```make-pseudo-wiki-draft.sh```, результатом его работы является файл ```pseudo-wiki-draft.txt``` - текстовый файл со статьями Вики.

Скрипт требует библиотек ```wikiextractor```, ```pymorphy3``` и  ```nltk```, ставятся через ```pip install```.

Запускается скрипт просто:

```
./make-pseudo-wiki-draft.sh
```

Скрипт:

* Скачивает архив (там много разных Вики с fandom)
* Извлекает файл Вики Дозоров
* Распаковывает его
* Удаляет историю (см. файл ```clean.py```, он взят из проекта [fandom_download](https://bitbucket.org/robvanderg/fandom_download)
* Осуществляет попытку замены терминов с учётом словоформ (```replace.py```)

2\. Далее в файле ```pseudo-wiki-draft.txt``` были произведены ручные замены терминов, получился файл ```pseudo-wiki.txt``` - скрипт заменяет не всё правильно, также некоторые термины присутствовали однократно и смысла кодировать их замену не было. Полный список замен живёт в ```terms_map.json```, он несколько неконсистентный с точки зрения словоформ и словосочетаний тк носит сугубо информационый характер.

3\. Далее скриптом ```split.sh``` файл ```pseudo-wiki.txt``` был преобразован в набор ```.md```-файлов в каталоге ```knowledge_base```:  
```
cat pseudo-wiki.txt | ./split.sh
```
