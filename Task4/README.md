### Описание

Решение состоит из набора скриптов:

* ```rag_query.sh``` - делает запросы в векторную БД, используя локальные эмбеддинги и OpenAI, передаёт в локальную LLM или OpenAI, какие модели использовать регулируется ключами ```--openai-embeddings``` и ```--openai-llm```
* ```bot.sh``` - Telegram-бот, работет по poll-модели, имя бота - **Practicum7Bot**, как с ним работать см. ниже
* ```rag.py``` - логика RAG
* ```bot.py``` - логика бота

### Запуск

Предполагается, что Qdrant запущен и наполнен, если это не так - см. Задание 2.

Для работы локальной модели нужно запустить сервер llama.cpp, который предоставляет API OpenAI:

Скачиваем модель Qwen2.5-1.5B-Instruct:

```
curl -L 'https://huggingface.co/Qwen/Qwen2.5-1.5B-Instruct-GGUF/resolve/main/qwen2.5-1.5b-instruct-q4_k_m.gguf?download=true' -O
```
Запускаем llama.cpp:

```
docker run --rm -p 8000:8000 -v .:/models ghcr.io/ggml-org/llama.cpp:server -m /models/qwen2.5-1.5b-instruct-q4_k_m.gguf --host 0.0.0.0 --port 8000 -c 4096 --repeat-penalty 1.15 --repeat-last-n 256 --dry-multiplier 0.8
```

### Запросы из командной строки

```
./rag_query.sh "С кем взаимодействовал Мышь?"
Answer:
Мышь был боевым колдуном-калейдоскопом и постоянным напарником Хомячка.
```

```
./rag_query.sh --openai-embeddings --openai-llm "С кем взаимодействовал Мышь?"
Answer:
Мышь взаимодействовал с Хомячком — он был его другом и постоянным напарником.
```

### Некоторые замечания

* История сообщений не сохраняется и не передаётся в LLM, поэтому диалоги "Какой цвет глаз у Абрахаса?" - "Я не знаю" - "А вообще кто это?" - "Абрахас это ..." - невозможны
* Локальная модель "глупая" - поэтому количество чанков, которое передаётся ей на вход равно 3 (для OpenAI передаётся 5 чанков) 
* Локальная модель "глупая" - у неё нет просьбы объяснять шаги в prompt тк она путается от длинных промптов
* К сожалению даже для OpenAI не удалось добиться того, чтобы модель объясняла свой выбор, это переодически происходит, но редко:
