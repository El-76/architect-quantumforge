# architect-quantumforge

### Введение

Решение в коде отличается от решения из Задачи 1. В Задаче 1 выбраны флагманские модели, в коде - пригодные для запуска на CPU:

* codefuse-ai/F2LLM-v2-330M - эмбеддинги
* qwen2.5-1.5b-instruct - LLM

Также с целью получить лучшее качество код переключается на модели OpenAI (это противоречит выбору в Задании 1, но это осознанно - хотелось посмотреть на модели от OpenAI):

* text-embedding-3-large - эмбеддинги
* gpt-5.6-luna - LLM

Для API моделей OpenAI нужен ключ - см. ниже.

Предполагается, что задания оцениваются последовательно - в Задании 2 сгенерировали базу знаний, в Задании 3 запустили Qdrant и наполнили БД и тп - следующее задание может пользоваться артефактами предидущих.

### Окружение

Решения разработаны для Python 3.11.16.

Для установки необходимой версии Python использовался [pyenv](https://github.com/pyenv/pyenv):

```
pyenv install 3.11.16
```

Далее надо переключиться на эту версию:

```
pyenv global 3.11.16
```

Также должны быть установлены библиотеки:

```
pip install -r requirements.txt
```

Также необходим Docker.

### Секреты

Для работы решений нужны ключ API OpenAPI и токен Telegram бота.

Они физически располагаются в файле ```secret.envsh```, который импортируется в bash-скриптах заданий. В дереве проекта этот файл заархивирован с паролем, пароль - название финской компании, которая внедряет продукт QuantumForge Software из задания. Если вдруг понадобится разархивировать данный файл на Windows - используйте 7-Zip.
